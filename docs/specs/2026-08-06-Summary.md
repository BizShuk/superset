## 已遇到的問題點 (Encountered Problems)

| 日期 (Date) | 功能 (Feature) | 使用方式 (How to Use) | 價值 (Value) |
| ----------- | -------------- | --------------------- | ------------ |
| 2026-08-04 | Native PTY binding 造成跨平台安裝與打包失敗 | 執行 `npm run build`，確認 VSIX 不含 `node-pty` 或 fork | 改用 VS Code native terminal，移除 executable bit、prebuild 與 rebuild failure mode。 |
| 2026-07-26 | Terminal activity false positive 與 hot-path logging | 讓 background TUI 工作後再 idle，觀察只在 `seen → unseen` 時記錄 | 集中 suppression policy、排除 shell CPU，避免 output reading 與 log 本身拖慢 Extension Host。 |
| 2026-08-06 | Plugin activation partial failure 留下 resource | 執行 `Superset: Show Diagnostics` 並觸發 isolated provider failure test | Activation failure 與 reverse teardown 都清除 plugin-owned registrations，diagnostics 採 fail-soft。 |
| 2026-07-20 | Session virtual URI path 被 normalize 後找不到檔案 | 在 `Sessions` 點 session 開啟 summary，再 append JSONL 觀察刷新 | File identity 放在 URI query，cache 同時比對 size 與 mtime，watcher 只在 View visible 時存在。 |
| 2026-07-27 | mDNS stale secondary index 與惡意 payload | 讓同一 service 改 alias / address / port，再執行 `Connect` | Forward / reverse index 與 expiration 同步更新，transport limits 與 target validation 阻止錯誤合併與 command injection。 |
| 2026-08-05 | TODO mutation 遺失 method receiver | 在 TODO row 執行 Rename、Archive、Rollback 或 Change Priority | 所有 row mutation 經單一 dispatch boundary 呼叫 store，避免裸函式造成 `this.repository` 消失。 |
| 2026-08-06 | Git command 沿 parent repository 誤判目錄 | 在 repository 內的 non-repository parent / sibling 開啟 `Repo Path` 與 `Change` | 每個 Git operation 先確認 target folder 自己的 `.git` marker，避免顯示或修改錯誤 repository。 |
| 2026-08-05 | VS Code menu argument 跨層後 `instanceof` 靜默失敗 | 多選 `Repo Path` rows 後執行 Open、Remove 或 Create Subfolder | Command argument 採 duck typing 並統一走 `resolveEntries`，保留 inline 單列與 selection 多列語意。 |
| 2026-08-04 | Busy agent terminal 被重用後命令送進 TUI stdin | 同一路徑連續啟動相同 agent，前一個 execution 尚未結束 | 以 `(path, agent)` 追蹤多個 live terminals，pending / running 期間建立新 terminal。 |
| 2026-08-06 | 自訂 path filter 與 VS Code list state 分岔 | 在 `Repo Path` 按 `Cmd+F` 並切換 Filter / Fuzzy Match | 直接使用 native Find Control，不保留 extension-owned query、Clear command 或全域 list setting。 |
| 2026-08-06 | Git status 遇到 rename、copy 或特殊字元路徑解析錯誤 | 建立 rename / copy / conflict 後刷新 `Change` | 只接受 NUL-delimited porcelain v1，並將 index 與 working-tree delta 分別投影到正確 group。 |
| 2026-08-06 | Discard 可能永久刪除 untracked / newly staged file | 在 `Change` 對 group、folder 或 file 執行 `Discard` | 先顯示 modal confirmation，具回復需求的檔案送入 VS Code Trash。 |
| 2026-08-06 | Superset commit workflow 與 native SCM 重複且增加 target state | 直接在 VS Code Source Control 輸入、產生並提交 commit message | `Change` 不再擁有 Input Box、message generation、handoff 或 direct commit path，避免兩套 SCM state 分岔。 |
| 2026-08-06 | Editor Layout 使用小數比例造成 sibling group 看似消失 | 建立 `2×2` editor groups 後切換 max modes 與 active group | 使用同量級 integer pixel allocation、ratio signature 與 `viewColumn` active index，維持 topology 與最小 sibling share。 |
| 2026-07-27 | 已刪 source 的 stale JavaScript 仍被打進 VSIX | 刪除 TypeScript source 後執行 `npm run build` | Build 先 clean `out/`，artifact verifier 拒絕無 source 對應的 compiled module。 |
